# Habit Tracker

A clean, minimalist, dark-themed daily habit tracker built with ReactJS, ES6+, and pure Vanilla CSS.

> **Task 2:** Interactive JavaScript and ReactJS Application Development  
> **Course:** Full Stack Web Development  
> **Group 2:** Daily Life and Productivity Applications  
> **Problem Statement 13:** Personal Habit Tracker  
> *"Track daily habits such as reading, exercise, water intake, and meditation."*

---

## Features

- **Today's Checklist:** Track daily routines (Reading, Exercise, Water Intake, Meditation, and Custom Habits) with intuitive check toggles and inline numeric counters (`+` / `-`).
- **Weekly Matrix:** A 7-day adherence grid allowing users to inspect and toggle past days with calculated completion percentages.
- **Habit Management (CRUD):** Add new habits, edit goals, or remove habits with client-side form validation (title length, positive targets, duplicate name prevention).
- **Streak Calculation:** Calculates consecutive active days per habit.
- **LocalStorage Sync:** Automatic persistence of habits and progress across browser reloads.
- **Minimalist Aesthetic:** Focused dark theme with centered layout and zero visual clutter.

---

## Tech Stack

- **React 18** (Components, JSX, `useState`, `useEffect`, `useMemo`)
- **JavaScript ES6+**
- **Vanilla CSS3** (Flexbox, CSS Grid, clean custom properties)
- **Vite**
- **Lucide React** (icons)

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the dev server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
